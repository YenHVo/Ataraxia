The requirements this program is designed to achieve are the following:
- Users can authenticate and log in. 
- Different user roles have different user interfaces and permissions.
- Administrators can create/edit/delete rooms.
- Employees must be assigned to an administrator in order to make reservations.
- Managers must be assigned to an administrator in order to see reports, make adjustments, and other features.
- Guests can check-in and check-out, request services, and other features.
